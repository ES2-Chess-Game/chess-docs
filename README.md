# Jogo de Xadrez

Repositório de documentação do projeto de jogo de xadrez, desenvolvido no contexto de Engenharia de Software 2 (UFF). Os códigos-fonte são mantidos em dois repositórios independentes.

## Visão geral

O estado atual do código contém uma aplicação web com tabuleiro interativo e um backend que cria partidas, valida movimentos básicos e alterna os turnos. Este README apresenta o mapa do projeto; detalhes de execução, arquitetura e comportamento implementado estão nos READMEs dos respectivos repositórios de código.

## Repositórios

- Os três projetos são repositórios Git independentes. Os links abaixo apontam para seus READMEs no GitHub, não para caminhos relativos entre pastas locais.

| Repositório | Responsabilidade e documentação |
| --- | --- |
| [chess-docs](https://github.com/ES2-Chess-Game/chess-docs#readme) | Documentação do projeto, planejamento e requisitos. |
| [chess-frontend: README](https://github.com/ES2-Chess-Game/chess-frontend#readme) | Interface web, execução local e integração com a API. |
| [chess-backend: README](https://github.com/ES2-Chess-Game/chess-backend#readme) | API, regras implementadas, arquitetura e execução do servidor. |

Para iniciar ou usar a aplicação, consulte os READMEs do frontend e do backend. Eles documentam os comandos próprios de cada repositório e as limitações atuais do código.
